\# SAP FICO Implementation — Project Planning \& Documentation



This repository contains the planning, strategy, and supporting documentation

produced during a simulated SAP FICO (Financial Accounting \& Controlling)

module implementation for a fictional mid-sized manufacturing company,

Meridian Industrial Products Pvt. Ltd.



\## Contents

\- \*\*week-01-project-planning-strategy/\*\* — Project charter-level planning,

&#x20; phased implementation plan (Initiation → Planning → Execution →

&#x20; Monitoring \& Control → Closure), timeline, resource allocation, budget,

&#x20; and risk assessment.



\## Module Scope

\- \*\*FI\*\*: General Ledger, Accounts Payable, Accounts Receivable,

&#x20; Asset Accounting, Bank Accounting

\- \*\*CO\*\*: Cost Element Accounting, Cost Center Accounting, Internal Orders,

&#x20; Profit Center Accounting, COPA



\## Methodology

SAP Activate (Prepare–Explore–Realize–Deploy–Run) aligned with PMBOK

process groups (Initiation, Planning, Execution, Monitoring \& Control, Closure).
